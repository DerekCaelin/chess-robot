# AGENTS.md — standing rules for agents in this repository

## Git / GitHub

- **Never push to GitHub — or any git remote — without Derek's explicit
  consent.** This includes `git push`, force-pushes, creating pull
  requests or issues, and publishing the repository anywhere online.
  Committing locally is fine. When a push seems useful, ask first and wait
  for a clear yes.
